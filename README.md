# Project Titan Core

A NeoForge mod for Minecraft 1.21.1 centred on the **Titan Core** — a multi-input crafting block that consumes items, energy (FE), and fluid to produce a 10-tier chain of **Titan Shards** (Mote → Heart of the Titan). Each shard feeds the next tier's recipe; the chain is the spine of the Project Titan modpack's progression.

- **Mod ID:** `projecttitancore`
- **Minecraft:** 1.21.1
- **NeoForge:** 21.1.228
- **Java:** 21
- **Author:** lind3r

## Current content

- **Titan Core** block + block entity with a custom GUI (9 input slots, 1 output slot, FE energy bar, fluid gauge, progress arrow).
- **Custom recipe type** driven by JSON: 10 tiered chain recipes (`titan_core_t1` … `titan_core_t10`).
- **Titan Shards** in 10 tiers (`mote_of_the_titan` … `heart_of_the_titan`); each tier consumes the previous shard plus 8 bulk ingredients and a tier-appropriate fluid.
- **Crafting beam** rendered above an active core, with emitted light at full intensity while crafting.
- **Holographic Titan projection** above the beam — translucent voxel statue that grows as tiers are completed, in 10 cumulative anatomy slabs (plinth/feet → crowned head, one per tier).
- **Holy sky tint** while any nearby Core is crafting — fog/sky biases toward holy gold, decays smoothly when crafting stops.
- **Ambient sound loops** — a quiet organ-pad hum whenever a Core's projection is visible, plus a bell-and-drone layer while crafting.
- **Apothic World Tier bridge** — completing each shard's FTB quest auto-advances the player's Apotheosis World Tier (Haven → Pinnacle), front-loaded so Mythic loot lands before the endgame fight.
- **Titan Trial** — Tier 10 unlocks a Gateways to Eternity boss gauntlet (three Cataclysm bosses at ×2 health and damage) that drops the **Crown of the Titan**, the modpack-completion trophy.
- **Holy bricks** building set with Chisel Modern carving-group integration.
- **Holy** visual theme — ivory marble + gold, with halo and sunburst motifs.

## Building

Run from the repo root:

```bash
./gradlew build                # build the mod JAR (output: build/libs/)
./gradlew runClient            # launch a dev client with the mod loaded
./gradlew runServer            # launch a dedicated dev server
./gradlew runData              # run data generators (output to src/generated/resources/)
./gradlew runGameTestServer    # run NeoForge GameTests headlessly
./gradlew clean
./gradlew --refresh-dependencies
```

## Repository layout

```
src/main/java/                 # mod sources
src/main/resources/            # assets, data, models, lang, recipes, loot tables
src/main/templates/            # neoforge.mods.toml template (edit here, not the generated copy)
src/generated/resources/       # data-generator output (auto-included in JAR)
scripts/                       # Python helpers for generating block/item textures
```

Notable paths:

- Language strings: `src/main/resources/assets/projecttitancore/lang/en_us.json`
- Recipes: `src/main/resources/data/projecttitancore/recipe/`
- Loot tables: `src/main/resources/data/projecttitancore/loot_table/blocks/` (singular `loot_table`, per the 1.21 rename)

## Asset generation

Most non-code assets are generated by Python scripts rather than hand-edited:

- `scripts/gen_block_texture.py` — generates the Titan Core block textures: `titan_core_frame.png` and `titan_core_glass.png` (16×16) for the gold-cage block model, plus `titan_core.png` / `titan_core_active.png` (32×32) for the legacy single-face motif. Pluggable centre motif (`MOTIFS` dict).
- `scripts/gen_shard_texture.py` — generates the 10 Titan Shard item textures from a shared silhouette + per-tier palette.
- `scripts/gen_relic_texture.py` — generates trophy-relic item textures (currently `crown_of_the_titan.png`) using the same grid+palette pattern as the shards.
- `scripts/gen_building_block_texture.py` — generates the holy_bricks variant set (32×32 tileable).
- `scripts/gen_titan_structure.py` — generates the holographic Titan projection voxel data plus per-tier preview images.
- `scripts/gen_beam_texture.py` — generates `titan_beam.png`, the bundled white beam texture used by the crafting beam.
- `scripts/gen_holy_sounds.py` — synthesises the two ambient OGG loops (`titan_core_idle`, `titan_core_crafting`).

Edit colours/layout/parameters in the script and re-run; do not hand-edit the generated assets.

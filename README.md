# Project Titan Core

A NeoForge mod for Minecraft 1.21.1 centred on the **Titan Core** — a multi-input crafting block that consumes items, energy (FE), and fluid to produce tiered **Trophy** items over a long crafting cycle. Trophies are intended to drive progression hooks (Better Questing integration) and unlock larger in-world structures (planned).

- **Mod ID:** `projecttitancore`
- **Minecraft:** 1.21.1
- **NeoForge:** 21.1.228
- **Java:** 21
- **Author:** lind3r

## Current content

- **Titan Core** block + block entity with a custom GUI (9 input slots, 1 output slot, FE energy bar, fluid gauge, progress arrow).
- **Custom recipe type** driven by JSON: tier 1, tier 2, tier 3, plus a fast test recipe.
- **Trophy items** in three tiers (`trophy_tier_1` … `trophy_tier_3`).
- **Crafting beam** rendered above an active core, plus emitted light at max level while crafting.
- **Holy** visual theme — ivory marble + gold, with halo and sunburst motifs.

## Planned

- Better Questing integration: detecting a trophy in inventory completes the matching quest.
- In-world structure construction once a trophy is produced (design pending).

## Building

Run from the repo root:

```bash
./gradlew build                # build the mod JAR (output: build/libs/)
./gradlew runClient            # launch a dev client with the mod loaded
./gradlew runServer            # launch a dedicated dev server
./gradlew runData              # run data generators (output to src/generated/resources/)
./gradlew runGameTestServer    # run NeoForge GameTests headlessly
./gradlew clean
./gradlew --refresh-dependencies
```

## Repository layout

```
src/main/java/                 # mod sources
src/main/resources/            # assets, data, models, lang, recipes, loot tables
src/main/templates/            # neoforge.mods.toml template (edit here, not the generated copy)
src/generated/resources/       # data-generator output (auto-included in JAR)
scripts/                       # Python helpers for generating block/item textures
```

Notable paths:

- Language strings: `src/main/resources/assets/projecttitancore/lang/en_us.json`
- Recipes: `src/main/resources/data/projecttitancore/recipe/`
- Loot tables: `src/main/resources/data/projecttitancore/loot_table/blocks/` (singular `loot_table`, per the 1.21 rename)

## Texture generation

Block and trophy textures are generated by Python scripts rather than hand-edited:

- `scripts/gen_block_texture.py` — generates `titan_core.png` and `titan_core_active.png` (32×32).
- `scripts/gen_trophy_texture.py` — generates trophy item textures; add a tier by extending `TIERS` and `PIXEL_GRIDS`.

Edit colours/layout in the script and re-run; do not hand-edit the PNGs.
